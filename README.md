**how i approach engineering**

- **product first:** understand the problem and the user before deciding how to build the solution.
- **full-stack thinking:** consider the interface, APIs, data model, and backend workflows as parts of one system.
- **maintainable code:** prefer clear structure, reusable components, and modular implementations over unnecessary complexity.
- **scalability with purpose:** build a sensible foundation that can evolve with new features and growing requirements, rather than overengineering too early.
- **continuous learning:** strengthen fundamentals, experiment with new technologies, and learn by building and debugging real applications.
